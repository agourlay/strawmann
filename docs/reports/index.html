strawmANN run reports

Each page is one full benchmark run, self-contained and needing no network. It states its own licence in the header: the gate verdict per arm, the conformance tier and hash, the environment hash, the pass count, and a banner on every row the comparison refuses. Read that before quoting a number off it.

T4 with T3 passing, gate pass both arms, 3 passes, equal-work, matched oversampling, --perf, the same Qdrant binary as the 09-24 page. No contaminated or drifting row. At matched recall strawmANN serves 1.26x to 1.44x Qdrant's throughput. First page with ACORN-1 filtered search; its W11 rows append 10x slower than 09-24's, so no ratio crosses the two pages.

The pages are not a series. Between 09-07 and 09-08 the bfb pin moved, W12 became two rows, its query count went from 5,000 to 50,000, W11's append became throttled, and Qdrant was rebuilt twice, so compare.py refuses ratios across them as STALE. Between 09-21 and 09-23 only the strawmANN build and the recorded oversampling policy changed, and the refusal holds there too. Read each page against itself.
