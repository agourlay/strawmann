strawmANN run reports

Each page is one full benchmark run, self-contained and needing no network. It states its own licence in the header: the gate verdict per arm, the conformance tier and hash, the environment hash, the pass count, and a banner on every row the comparison refuses. Read that before quoting a number off it.

  • dbpedia-openai-1m, 2026-09-25
    The current dbpedia-openai-1m comparison, and the source of comparison-dbpedia-openai-1m.md. T4 with T3 passing, gate pass both arms, 3 passes, equal-work, matched oversampling, --perf, the same Qdrant binary as the 09-24 page. No contaminated or drifting row. At matched recall strawmANN serves 1.26x to 1.44x Qdrant's throughput. First page with ACORN-1 filtered search; its W11 rows append 10x slower than 09-24's, so no ratio crosses the two pages.

The pages are not a series. Between the two dbpedia-openai-1m pages the harness's settle discipline and W11's append rate changed, so compare.py refuses ratios across them as STALE. Read each page against itself. Superseded pages are retired to the repository's git history.
