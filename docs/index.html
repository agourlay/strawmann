strawmANN

A deliberately unfair strawman for approximate nearest neighbour search

A Qdrant-wire-compatible vector engine in Zig, built as a performance oracle: no compatibility debt, no distribution, no product. These are its benchmark runs against Qdrant 1.20.

Each report is one self-contained run, and states its own licence in its header: the gate verdict per arm, the conformance tier, the pass count, and a banner on every row the comparison refuses. The reports are not a series: when the harness configuration changes between runs, compare.py refuses ratios across them as STALE. Superseded reports are retired to the repository's git history.

Disclosure: the author works at Qdrant, on the engine being measured. Nothing here is a Qdrant position and nobody at Qdrant has reviewed it.
